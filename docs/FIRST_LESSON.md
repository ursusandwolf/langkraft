# Первое занятие в Langkraft

## Пробное занятие без внешних сервисов

Из корня проекта:

```powershell
./gradlew.bat :webApp:jsBrowserDevelopmentWebpack
cd tools/web-storage-tests
npm ci
npx playwright install chromium
npm run demo
```

Откроется отдельное окно Chromium с временным профилем. В этом режиме вход не нужен: сервер возвращает заданные переводы «Hallo» и «Welt», а вместо речи звучит четырёхсекундный сигнал. YouTube и Gemini не вызываются.

Окно можно уменьшать и разворачивать: интерфейс подстраивается под его размер. Проверка навигации в уменьшенном окне: `npm run test:demo` из `tools/web-storage-tests` (открывает и закрывает Chromium).

Откройте **Learn**, импортируйте `https://youtu.be/video`, откройте материал и нажмите PLAY. Нажмите слово **Hallo**, затем **ADD TO DICTIONARY**. В **Review** пройдите **SHOW ANSWER → AGAIN → SHOW ANSWER → GOOD**, затем перезагрузите страницу и посмотрите **Stats**.

Результат сохраняется при перезагрузке внутри этого окна. Закрытие вкладки с приложением завершает пробное занятие и удаляет временный профиль; для новой попытки запустите `npm run demo` снова. Этот режим проверяет понятность интерфейса, а не качество речи, перевода или синхронизацию аккаунтов.

## Занятие с реальным материалом

Для локального запуска откройте [инструкцию запуска](RUNNING.md), затем Web-приложение на `http://127.0.0.1:3000`. Для первого занятия используйте одно короткое немецкое видео с немецкими субтитрами.

1. Без AI вход не нужен. Если провайдер настроен и нужны AI-подсказки, войдите через **Account**.
2. В **Learn** вставьте ссылку YouTube в **YouTube URL**, нажмите **IMPORT** и дождитесь появления материала в **Your Library**. При ошибке прочитайте сообщение, исправьте ссылку или повторите попытку.
3. Откройте материал и включите воспроизведение. Проверьте, что слышите аудио и видите немецкие реплики.
4. Нажмите незнакомое слово в реплике. Введите перевод вручную либо отредактируйте AI-подсказку и нажмите **ADD TO DICTIONARY**.
5. Перейдите в **Review**, нажмите **SHOW ANSWER**. **AGAIN** вернёт слово в текущее занятие; **GOOD** после первого успешного ответа назначит следующее повторение через день. Дождитесь окончания сохранения.
6. Перезагрузите страницу. Материал остаётся в **Learn**, а слово после **GOOD** не должно сразу снова появиться в **Review**. На **Stats** виден текущий статус повторений.

Если сохранить оценку не удалось, карточка остаётся на экране с сообщением. Повторите оценку после устранения проблемы.

В деморежиме перевод заранее задан. В обычном приложении без AI перевод вводится вручную; подключение Gemini, Claude или совместимого API описано в [AI](AI.md).

## Что записать после проверки

- На каком шаге понадобилась помощь или было непонятно, что нажимать.
- Получилось ли прослушать материал, сохранить слово и закончить повторение.
- Сохранился ли результат после перезагрузки; если нет — точные шаги и текст ошибки.

Автоматическая проверка этого пути: `npm run test:app` в `tools/web-storage-tests` после Web-сборки. Она запускает отдельный локальный fixture-сервер и изолированный Chromium; пользовательский профиль браузера не используется. Результат теста не заменяет проверку с участником.

Обычный backend по умолчанию работает без AI: перевод слова вводится вручную. Ошибка AI не блокирует сохранение заполненной карточки. [Настройка Gemini, Claude и совместимых API](AI.md).
