## Контекст

Langkraft — приложение для изучения немецкого: YouTube URL → async job → извлечение MP3, субтитров, метаданных и waveform → библиотека → прослушивание → перевод и сохранение слова. Offline-аудио скачивается отдельно по действию пользователя.

- Рабочие клиенты — Web, Desktop и TUI. Android target отключён; его сборка не подтверждена.
- Kotlin Multiplatform, Compose Multiplatform, Ktor, SQLDelight; версии смотри в Gradle-файлах.
- Backend вызывает yt-dlp отдельными аргументами без shell. Для настоящего импорта нужны Node.js 22+, yt-dlp и FFmpeg.
- Web хранит SQLite/WASM в worker с IndexedDB VFS; аудио — отдельно в IndexedDB, частями.
- `DatabaseAccess` сериализует доступ репозиториев к одному соединению. `PlayerViewModel` владеет дочерней coroutine scope и управляет платформенным плеером.
- SRS, JWT-авторизация и синхронизация реализованы. Перевод использует Gemini при наличии ключа, иначе mock. Реальный платный API не проверен. PWA/service worker не добавлен.

Начни с `README.md`, `docs/PROJECT_CONTEXT.md`, `docs/DATA_LAYER.md`, `docs/SUBTITLES.md`, затем прочитай исходники. Сначала сформируй собственные выводы; после этого сопоставь их с `docs/CODE_REVIEW_2026-10-21.md`. Последний документ содержит первоначальные находки и отдельный раздел с последующими исправлениями: не объявляй исправленную находку актуальной без проверки текущего кода.

## Приоритетные проверки

1. **Импорт и процессы:** URL, метаданные, субтитры, таймаут, завершение дочерних процессов и временные файлы. Принятый job продолжает работу после закрытия POST. По умолчанию 4 worker + 8 queued jobs; переполнение даёт 503/Retry-After. Длительность ограничена четырьмя часами. Остановка сервиса отменяет задания и процессы.
2. **Данные и миграция:** атомарность content/subtitles, FK, ссылки слов, SRS, tags, pending sync и серверные tombstones. Схема v3 принимает исторические dev v0/v1 и main v1/v2. Проверить backup, ordinal, waveform, повторный импорт и восстановление отсутствующих локально source refs. Старые реплики с ordinal 0 упорядочиваются по ID.
3. **Согласованность SQLite и аудиохранилища:** ошибки/отмена до и после публикации аудио, сбой финального сохранения ссылки, квота, неполные загрузки и непривязанные объекты.
4. **Web worker и IndexedDB:** очередь сообщений, транзакции и rollback, закрытие/таймаут worker, жизненный цикл Blob URL, открытие нескольких вкладок и обновление наблюдаемых списков.
5. **Плеер и UI:** гонки загрузки/перевода/сохранения, устаревшие ответы, восстановление состояния после ошибки, retry, seek, освобождение scope и аудиоресурсов, доступность ключевых действий.
6. **Контракты и сборка:** HTTP-ответы, разрешение media URL, Range, единый origin/proxy, разделение платформ, соответствие документации фактическому поведению.

Известные открытые направления: общая квота downloads/retention, аварийные непривязанные объекты и координация вкладок. Ограничение длительности уже реализовано. Отделяй эти ограничения от новых находок и учитывай доверенный локальный запуск либо публичное размещение.

## Правила проверки

- Каждую находку обоснуй сценарием, цепочкой вызовов и точным участком кода. Разделяй воспроизведённое поведение, вывод из статического анализа и гипотезу.
- Сначала корректность и потеря данных, затем безопасность/ресурсы, затем дизайн. Не предлагай переписывать архитектуру без связи с конкретным дефектом.
- Не выдавай запланированные возможности за регрессии MVP. Для UI и Android явно укажи границы проверки.
- Если запускаешь команды, запиши результаты. Не утверждай, что тесты прошли, если их нет в архиве. Сведения автора о проверках и CI приведены в `docs/INTEGRATION_COMPLETION.md`; это не твои независимые результаты.
- Для статического ревью внешние сервисы и ключи не нужны. Без отдельного запроса не обращайся к YouTube, не развёртывай приложение и не публикуй результаты.

При доступном JDK 21 и Node.js 22+ можно проверить компиляцию без исключённых тестов (на Windows замени `bash ./gradlew` на `.\gradlew.bat`):

```shell
bash ./gradlew :shared:compileKotlinDesktop :backend:classes :shared:compileKotlinJs
bash ./gradlew :webApp:jsBrowserDevelopmentWebpack
bash ./gradlew :webApp:jsBrowserProductionWebpack
```

Команды сборки требуют сети. Development и production запускай отдельными вызовами Gradle. Полный CI из ZIP воспроизвести нельзя, поскольку тестовые исходники и инструменты исключены.

5. Заверши перечнем того, что по архиву проверить не удалось.

Если подтверждённых дефектов нет, сообщи это прямо. Не заполняй отчёт неподтверждёнными проблемами или замечаниями о форматировании ради количества.
