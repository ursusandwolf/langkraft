Responsibilities: LocalContentRepository, RemoteContentSource and AudioDownloader separate persistence, async ingest polling and streaming offline storage. StateViewModel and delegates manage UI. AudioPlayer bridges Web/VLC/ffplay; LinguisticAssistant strategies are cached by a decorator. SRS uses the SM-2 strategy. Client schema v3 supports migration from both historical branches, full SRS, pending sync, tags and waveform.

Backend imports are persistent bounded jobs; closing a POST does not cancel an accepted job. Service shutdown cancels workers and process trees. URL validation, timeouts, strict subtitles and per-job media paths protect ingestion. Media serves HTTP Range. Sync includes tombstones, server cursor and local revision-aware acknowledgements.
