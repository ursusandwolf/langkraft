# MVP Langkraft

Цель: пользователь проходит одно занятие по немецкому — добавляет материал, слушает с субтитрами, сохраняет слова и повторяет их позже.

Первая версия — Web в современном desktop Chromium, с backend для небольшой закрытой проверки; платформа подтверждена пользователем. Публичный многопользовательский запуск требует отдельной оценки.

## Граница первой версии

- Импорт YouTube с поддерживаемыми немецкими субтитрами: видимый процесс, понятный отказ и повтор.
- Библиотека, воспроизведение, переход к реплике и повтор фрагмента.
- Сохранение слова с контекстом и ручным переводом без AI и аккаунта. AI-подсказка необязательна: для неё нужны аккаунт и настроенный провайдер backend. [Режимы AI](AI.md).
- Повторение слов: показать ответ, оценить, сохранить результат, продолжить занятие.
- Библиотека, словарь и расписание повторений сохраняются после перезагрузки браузера.

Offline-аудио, sync и остальные реализованные возможности сохраняются. Их расширение не является условием первого пилота.

## Приоритеты

1. **MVP-01:** при отказе сохранения SRS карточка остаётся на экране; видна ошибка; повторная оценка доступна. Во время сохранения повторные нажатия не создают дополнительные результаты. Ошибка чтения очереди отличается от отсутствия слов.
2. **MVP-02:** проверить весь учебный путь в интерфейсе: импорт → прослушивание → слово → повторение → перезагрузка. Сначала использовать воспроизводимый fixture, затем реальное видео и ручной перевод. Проверка живого AI выполняется отдельно при настроенном провайдере. Фиксировать только мешающие этому пути ошибки.
3. **MVP-03:** дать участнику короткую инструкцию первого занятия и провести закрытую проверку. Наблюдать, может ли он без объяснений разработчика добавить материал, сохранить слово и завершить повторение. Записать конкретные затруднения перед следующими изменениями.

## Приёмка первого занятия

- После успешного импорта материал виден в библиотеке, воспроизводится, содержит субтитры.
- Сохранённое слово содержит исходное слово, перевод и контекст; после перезагрузки оно доступно для повторения по расписанию.
- Оценка карточки меняет расписание только после успешного сохранения. При отказе можно повторить действие, не потеряв карточку.
- После перезагрузки успешная оценка сохранена; повторное обучение AGAIN остаётся доступным в текущем занятии.
- Ошибки импорта, перевода и сохранения видны пользователю; действие можно повторить.

Автотесты подтверждают воспроизводимые сценарии. Реальный импорт, качество перевода и наблюдение за участником проверяются отдельно; зелёный CI сам по себе не означает готовый MVP.

Для участника: [первое занятие](FIRST_LESSON.md). По решению пользователя текущую проверку MVP-02 выполняем на fixture-сервере; реальный Gemini сейчас не требуется. Проверка качества реального перевода остаётся отдельным шагом перед оценкой учебной пользы.

Для ручной проверки без настройки backend доступен `npm run demo` в tools/web-storage-tests после Web-сборки. Он открывает отдельный временный Chromium и не выполняет шаги занятия за участника. Отзыв участника записывается отдельно от результатов автотестов.

## Отложено до потребности

Потоковые recovery-архивы и большие библиотеки; автоматическая retention клиентского аудио; сложная политика аккаунтов/профилей и общая межвкладочная сериализация; новые платформы; новые AI-режимы и рефакторинг архитектуры без дефекта основного сценария.

Уже добавленные защиты данных сохраняются. При обычной ошибке нехватки места достаточно понятного отказа и возможности удалить ненужную копию; автоматическую очистку библиотеки в MVP не вводим.
